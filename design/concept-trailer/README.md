## Honest labels

Every still and mockup carries visible "TARGET RENDER — not gameplay capture" treatment (image-gen key art,

the owner as shipping game footage.

## Constraints honored

- One consistent art direction (Ash & Circuitry — see bible); coherence over volume.
- Races are strictly myth-literary fiction — no real-world religious/ethnic/group imagery; the Chorus is machinery.
- Mobile-first (390px portrait mockups, 44px floor, thumb-reach), WCAG AA contrast, dark-theme tokens verbatim.
- Money mandate: the mockups show earned state only — earn-only badges, no purchase surfaces, no urgency theater (G1–G4).
- **Do NOT publish this anywhere** — it ships to the repo + PR only (WORKFLOW.md: no publish from design sessions).
